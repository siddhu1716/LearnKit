# LearnKit Procedural Memory

LearnKit is available through MCP. Use `learnkit_context` before repeating prior work, `learnkit_procedures` to inspect learned workflows, and `learnkit_status` for diagnostics.

VS Code Copilot currently lacks a user-prompt lifecycle hook in this integration, so automatic task-to-procedure learning is partial. Treat procedures as guidance and keep normal tool approvals enabled.
