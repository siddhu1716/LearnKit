# Changelog

All notable changes to LearnKit are documented here.

## [Unreleased]

### Added

- Coding-agent integration bundles for Claude Code, GitHub Copilot CLI, Codex CLI, Gemini CLI, Antigravity CLI, Antigravity IDE, and VS Code Copilot.
- Read-only MCP server with status, search, procedure listing, and task-context tools.
- Cross-process lifecycle-hook capture with bounded payloads and secret redaction.
- Stable host identities for plugin-originated dashboard runs.
- Developer installation and release documentation.

### Changed

- Exact procedure matching preserves token order and repetition.
- Replay no longer marks a run successful when a tool is missing or failed.
